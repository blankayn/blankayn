# Add this design to your GitHub profile

1. Create a public repository named `blankayn` under your `blankayn` account, or open it if it already exists.
2. Upload `README.md` to the repository root and `header.gif` inside an `assets` folder. Keep the folder structure below.
3. Commit the files. GitHub displays the README on your profile.

```text
blankayn/
├── README.md
└── assets/
    └── header.gif
```

The banner is an animated GIF with a 15-second loop: sunrise (0–4 seconds), daylight (4–6 seconds), sunset (6–10 seconds), night (10–13 seconds), and a return to dawn (13–15 seconds). The sun, mountains, water, stars, and moon are drawn with ASCII characters. The header background automatically fades from warm daylight to dark night during the loop.

The animation changes the header's appearance. It cannot change GitHub's page theme. It follows its own loop, independent of the viewer's time of day or theme setting.

The tech stack sits directly below the header and uses native Markdown/HTML styling, so it follows the reader's GitHub theme. There are no third-party image services or API keys to configure.

`header-preview.png` shows three stills from the animation. The other PNGs in `assets` are optional previews; only `header.gif` is required by the README.

The introduction is proposed profile copy based on your public repositories. Edit it to match your preferred wording before publishing.
